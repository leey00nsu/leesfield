# Cinema movement 자산 출처

움직임 미리보기는 이 프로젝트를 위해 직접 생성한 AI 영상이다. Higgsfield의 영상·poster를 복제하지 않았다.

- 시작 이미지: Viggle Turbo / Qwen-Image-2.1, v0.3 LoRA r256, 6 steps, Enhance Off, 1376×768.
- 영상: Google Flow, Omni 1.1 Flash, 720p, 6초, 16:9, 시작 프레임1장.
- 인물·카페 참조: 사용자 제공 메인 사진. 제품/POV는 직접 생성한 장면.
- 제품 파일: H.264 MP4, 음성 제거, faststart. Google Flow 출력의 표시는 유지한다.
- poster: 영상 첫 프레임에서 생성한384px 정사각 WebP.

2026-10-11 제작한33종의 채택 영상과 poster를 연결했다. 실제 움직임·방향·연속성을 확인했으며, 구별이 약했던8종은 참조나 지시를 보완한 두 번째 시안을 채택했다. 최종 목록과 실제 입력 문구, 이미지 seed·참조 hash, Flow 결과 ID, 원본·제품 hash, 변환·평가는 [movement-manifest.json](./cinema/movement-manifest.json)에 기록한다. Flow가 노출하지 않는 영상 seed는 추정하지 않는다.

동작을 비교하기 위한 예시이며 실제 생성 모델의 출력이나 정밀한 광학·카메라 궤적을 보장하는 자료로 제시하지 않는다.
